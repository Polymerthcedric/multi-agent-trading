# Multi-Agent Trading

An autonomous trading system built on 6-agent consensus, MCTS look-ahead, and self-learning feedback. Written in Python.

## The Stance
Trading shouldn't rely on emotional whims or single-point-of-failure algorithms. This system delegates decision-making to a consensus of agents. It is a fully autonomous money-making engine that removes human frailty from the execution loop. We trust math, structure, and relentless feedback.
